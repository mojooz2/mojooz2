### [BlueROV2 Underwater Sensor Integration](https://github.com/mojooz2/BlueROV2-Sensor-Integration-Modules)

<a href="https://github.com/mojooz2/BlueROV2-Sensor-Integration-Modules">
  <img src="https://raw.githubusercontent.com/mojooz2/BlueROV2-Sensor-Integration-Modules/main/media/photos/bluerov2_full_assembly_1.png" width="50%" alt="BlueROV2 underwater robot with integrated laser camera and imaging sonar mounts">
</a>

$\color{red}{\normalsize\textsf{\textit{Click the image to view the project repository.}}}$

A research internship project at POSTECH HERO Lab focused on designing and integrating custom sensor mounts for the BlueROV2 underwater robot.
I developed a two-axis pan–tilt mount for an underwater laser camera and a modular Oculus M1200d imaging sonar mount supporting 45° and 90° orientations.
The work included CAD modelling in Autodesk Fusion and SolidWorks, 3D printing, assembly, and integration with the ROV.
The completed hardware was documented through underwater testing footage and photographs.

A team project developed for the Cambridge Engineering Integrated Design Project. I was responsible for the robot's software, written in MicroPython for the Raspberry Pi Pico.

The robot uses line sensors, a QR code reader, and a time-of-flight distance sensor to navigate a track, collect boxes, and deliver them to specified locations.
